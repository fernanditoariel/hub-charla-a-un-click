# ¿Cómo competir cuando todo está a un click?

Micrositio con el material de la charla de **Miguel Hernández** (Director de CACE Región Sur)
en el Centro de Innovación del **Hub de Emprendedores de Bahía Blanca**, del 9 de septiembre de 2026.

Reúne, para compartir con quienes asistieron:

- 2 audios (resumen y conversación completa), generados con NotebookLM
- 1 video resumen
- 5 infografías descargables
- Los dos espacios abiertos del Centro de Innovación (Club de Emprendedores y Consultorio Emprendedor)
- Datos del expositor

## Stack

HTML + CSS + JS vanilla. Sin build step. Fuente (Space Grotesk) autoalojada en `assets/fonts/`.

## Deploy

Sitio estático en Vercel. Framework preset: **Other**. Build command: vacío. Output directory: raíz.
`vercel.json` define `cleanUrls` y los headers de caché.
